# How to execute ChopURL:

1. Clone the repository:
	```sh
	https://github.com/MMalpassi/ChopURL.git
	```

2. Create the virtual enviorment and install the required libraries:	
	```sh
	$ python -m venv chopurl_venv
	$ cd chopurl_venv/Scripts/activate
	$ pip install -r requirements.txt
	```

3. Run the server:
	```sh
	$ cd url_shortener/python manage.py runserver
	```

4. Open the port in your browser.
